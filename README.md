# Minimalistic terminal keyboard typing training( but without real words ).

## Controls:
**Esc** - exit the program
**Any key** - type the character 

## Dependencies:
Requires `ncurses` installed on your system.

## Note:
The size of the text depends on your terminal font. To make the font bigger, increase your terminal font.
